# PRODIGY_WD_03 - Tic Tac Toe 🎮

A responsive and interactive **Tic Tac Toe game** built with **HTML, CSS, and JavaScript**.  
Play in **Two Player mode** or challenge an **unbeatable AI** powered by the Minimax algorithm.

---

## ✨ Features
- 🎨 Grayscale theme with clean UI
- 👥 Two Player mode
- 🤖 Play vs AI (unbeatable)
- 🏆 Score tracking with reset option
- ♿ Accessible controls (keyboard + screen reader friendly)
- 📱 Responsive design for mobile and desktop
